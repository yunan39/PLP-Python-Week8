 Personal Mini-Toolkit

What It Does
The Personal Mini-Toolkit is a command-line Python application that consolidates three practical utilities into a single menu-driven program:
1. Dynamic To-Do List: Allows users to add, view, and remove tasks dynamically while the program runs.
2. Even Number Counter: Evaluates a numeric sequence up to a user-provided limit using loops and modulo arithmetic to count even numbers.
3. Simple Calculator: Processes basic arithmetic operations securely with robust error handling for unsupported operations or invalid inputs.

How to Run It
1. Ensure you have Python installed on your system.
2. Clone or download this repository.
3. Open your terminal or Visual Studio Code in the repository folder.
4. Run the program using the command:
   ```bash
   python toolkit.py
